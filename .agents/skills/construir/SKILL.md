# Construir

1. Confira se o pedido já tem um plano combinado, em `docs/planos/` ou na conversa. Se for uma tela, função ou regra nova e ainda não houver plano, use antes a skill `planejar`. Leia também as instruções do projeto e o fluxo mais parecido que já existe. Se o pedido vier do AI Squad, use a primeira versão combinada como limite.
2. Implemente uma parte que a pessoa consiga experimentar. Reutilize os componentes e as integrações já adotados pelo projeto.
3. Rode as checagens adequadas e, se a aplicação puder rodar, experimente o fluxo como alguém que vai usá-lo. Use dados de exemplo se precisar criar registros para o teste.
4. Mostre onde a mudança aparece, como experimentá-la e o que ficou pendente. Trate publicação como uma ação separada.
