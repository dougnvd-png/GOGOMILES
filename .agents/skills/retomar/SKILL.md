# Retomar

1. Leia o plano do AI Squad, os planos em `docs/planos/`, anotações de progresso e estado atual do Git, se estiverem disponíveis. Compare o que foi combinado com o que existe na aplicação.
2. Separe o que funciona no projeto local, o que está em revisão e o que foi publicado. Use PR, workflow e URL como evidência quando tiver acesso. Se não puder consultar produção, deixe esse estado como não verificado.
3. Aponte o próximo passo que mais aproxima a pessoa de uma versão utilizável. Se houver um bloqueio, diga qual decisão ou recurso destrava o trabalho. Faça o levantamento sem alterar o projeto.
