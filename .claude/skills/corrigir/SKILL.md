# Corrigir

1. Identifique onde o problema aparece e tente reproduzi-lo com o menor exemplo útil. Se não conseguir, use o erro e as evidências disponíveis para delimitar a causa.
2. Inspecione o caminho que produz o erro e faça uma correção focada. Preserve os dados, o trabalho local da pessoa e o comportamento dos fluxos vizinhos.
3. Repita o mesmo cenário e rode as checagens relevantes. Se faltar acesso, configuração ou um passo para reproduzir, explique exatamente o que impede confirmar a correção.
4. Diga o que causava o problema, o que mudou e como a pessoa pode conferir. Informe se a correção está local ou se a versão publicada já contém o ajuste.
